## 완본체 부품 계산기

완본체(조립 PC) 판매 페이지의 사양표를 읽어서, **'완본체 부품리스트&계산기' 시트**에 정리된 부품 스펙과 **다나와 최저가**로 견적표를 만들어 주는 스크립트입니다.
"이 완본체, 부품을 따로 사면 얼마일까?"를 몇 번의 클릭으로 확인할 수 있습니다.

- 원본 시트: https://docs.google.com/spreadsheets/d/1BzS5KSx11k-oaLxc37x33lahjWviZfCqObnbBw54D0I/edit
- 데이터(부품) 패치노트: https://docs.google.com/spreadsheets/d/1BzS5KSx11k-oaLxc37x33lahjWviZfCqObnbBw54D0I/edit#gid=1908038046

### 이런 걸 할 수 있어요

**견적 만들기**
- **사양표 읽기(OCR)**: 판매 페이지의 사양표 이미지를 골라 범위를 지정하면 글자를 읽어 부품을 찾습니다.
  - 캡처(Win+Shift+S) 후 패널에서 Ctrl+V로 붙여넣거나, 이미지 파일을 열어도 됩니다.
  - 사양을 글자로 복사해서 붙여넣어도 됩니다.
- **견적표**: 부품별 스펙·최저가·성능/추천 점수와 부품 합계를 보여줍니다.
  - 잘못 찾은 부품은 줄마다 다른 후보로 바꾸고, 잘못 읽은 글자는 "읽은 글자"를 눌러 고치면 그 줄만 다시 찾습니다.
  - SSD 용량, 케이스·쿨러 색상, 램 개수 같은 옵션을 고를 수 있습니다.
  - 튜닝램 패키지는 판매 페이지에 16GB×2로 적혀 있어도 32GB 1세트(세트 가격)로 계산합니다.
  - 가격은 직접 고칠 수 있고, 품절 부품은 비슷한 대안을 추천합니다.
- **평균 점수**: 시트의 성능·추천 점수로 견적 평균을 크게 보여줍니다(시트 계산기와 같이 케이스 제외).
- **호환성 검사**: 담은 부품끼리 문제가 없는지 확인합니다.
  - CPU·메인보드: 소켓, 램 규격, 메인보드 전원부, M.2 슬롯
  - 케이스: 메인보드 규격, 그래픽카드 길이, 쿨러 높이, 수랭 라디에이터(라디+팬 두께), 전면 C타입 포트
  - 파워: 용량, CPU 보조전원, 그래픽카드 8핀(케이블 가닥 수 기준, Y자 케이블을 써야 하면 따로 알려줌)
  - 팬리스 수랭 쿨러는 일반 25T 팬을 단 기준으로 계산합니다.
- **조립비**: 쿨러 종류(싱글공랭·듀얼공랭·수랭)를 보고 조립비를 자동으로 더합니다(컴퓨존 기준 3.5만·4만·4.5만원, OS 설치 +1만원). 끄거나 금액을 직접 바꿀 수 있습니다.
- **판매가 비교**: 판매가와 할인·적립을 넣으면 체감가와 부품 합계의 차이를 계산합니다.

**정리·공유**
- **상세 스펙**: 견적 부품의 주요 스펙(소켓·전원부·길이·높이·케이블 등)을 한 화면에 정리합니다. '전체 항목'으로 바꾸면 시트의 모든 스펙을 보여줍니다.
- **견적 저장·비교**: 견적을 저장해 두고 2~4개를 골라 나란히 비교합니다. 가격은 열 때마다 최신 데이터로 다시 계산합니다.
- **내보내기**: 표(커뮤니티 글쓰기용), 텍스트, 마크다운, 이미지로 복사할 수 있습니다. 부품마다 시트의 점수·가점·감점·이슈와 호환성 결과가 같이 들어갑니다.

**부품 찾아보기**
- **부품 검색·질문**: "B850M MAX GAMING 레인 공유", "7800X3D 소비전력", "PC801 단점"처럼 제품 이름 뒤에 궁금한 항목을 붙이면 그 값만 바로 보여주고, "9800X3D랑 B850M 박격포 호환"처럼 물으면 두 부품의 호환성을 검사합니다.
- **부품 추천 목록**: 종류를 고르면 추천 점수순으로 가격과 함께 보여줍니다. 성능 점수순·낮은 가격순으로 바꾸고 최대 가격을 정할 수 있습니다.
- **스펙 조건**: 원하는 스펙으로 걸러 볼 수 있습니다.
  - 예) 메인보드 '칩셋 이상 B650' + 'M.2 전체 슬롯 수 이상 4', 그래픽카드 '칩셋 이상 5070', 파워 'PCIe 케이블 가닥 수 이상 2'
  - 값 목록에서 여러 개를 체크할 수 있습니다(포함 = 하나라도 맞으면, 모두 포함 = 전부 맞아야, 제외 = 하나도 없어야).
  - 칩셋·등급 항목은 순서로 비교하고(B650E = B850, 그래픽카드는 NVIDIA·AMD 따로), 고른 항목의 비교 규칙은 조건 아래에 짧게 나옵니다. 자세한 설명은 ⓘ 버튼에 있습니다.

### 설치·업데이트
1. Tampermonkey(PC 크롬·엣지·웨일·파이어폭스)를 설치한 뒤, 이 페이지의 **설치** 버튼을 누릅니다.
2. 새 버전은 Tampermonkey가 자동으로 받아 옵니다(기본 하루 한 번). 바로 받으려면 Tampermonkey 대시보드에서 '업데이트 확인'을 누르세요.
3. **예전에 파일로 설치해 쓰던 분**은 기존 스크립트를 지우지 말고, 이 페이지에서 **설치만 다시 누르세요.** 같은 스크립트로 덮어써서 저장한 견적과 설정이 그대로 남고, 그 뒤부터 자동 업데이트가 됩니다.
   - 먼저 삭제하면 저장한 견적과 설정이 같이 지워질 수 있습니다.

### 사용 방법
1. 아무 페이지에서 **Alt+Shift+P**를 누르거나, Tampermonkey 메뉴에서 **"부품 계산기 열기/닫기"**를 누릅니다.
   - 단축키가 다른 기능과 겹치면 메뉴의 **"단축키 바꾸기"**로 바꿀 수 있습니다. (웨일 브라우저는 Alt+Shift+P가 겹칩니다)
   - 메뉴의 **"화면 버튼 보이기/숨기기"**를 켜면 화면에 "완본체 계산기" 버튼이 생깁니다. 버튼은 끌어서 옮길 수 있습니다.
2. **계산기** 탭에서 "페이지 이미지 고르기"로 사양표 이미지를 고르고, 사양 부분만 범위를 지정합니다.
3. **부품 찾기**를 누르면 견적표가 만들어집니다.
- 패널 위쪽의 **원본 시트**로 시트를 바로 열 수 있고, **패치노트**에서 데이터·스크립트 변경 내역을 볼 수 있습니다.

### 휴대폰에서 쓰기 (Android)
- **AdGuard for Android**의 사용자 스크립트(확장 프로그램) 기능으로 설치할 수 있습니다. 설치 후 메뉴의 "화면 버튼 보이기"를 켜거나, 화면 버튼으로 패널을 엽니다.
- 판매 페이지를 캡처한 뒤 **"이미지 파일"**로 캡처를 고르고, 손가락으로 끌어서 사양 부분을 선택하면 됩니다.
- 휴대폰은 PC보다 글자 인식이 느립니다. 아이폰용 AdGuard는 사용자 스크립트를 지원하지 않습니다.

### 데이터와 개인정보
- 다나와 최저가는 **매일 9시경·18시경** 자동으로 갱신되고, 부품 데이터는 공개된 구글 시트를 묶어 올린 파일(GitHub)에서 받아 옵니다. 데이터가 바뀌었을 때만 새로 받고, 그 파일을 받을 수 없으면 구글 시트에서 직접 받습니다. 바로 최신 데이터를 받고 싶으면 패널의 **새로고침**을 누르세요.
- 부품이 추가·삭제되면 처음 열 때 한 번 데이터 패치노트를 보여줍니다.
- OCR은 **내 브라우저 안에서** 실행됩니다(tesseract.js). 읽은 이미지는 어디에도 전송하지 않습니다.
  - 처음 OCR을 쓸 때 글자 인식 데이터를 CDN(jsDelivr)에서 한 번 내려받습니다.
- 로그인, 계정, 광고, 사용 기록 수집이 없습니다.

### 알아 두세요
- 부품 가격은 **다나와 최저가 기준**이고, 조립비는 컴퓨존 기준입니다. 실제 구매가와 다를 수 있습니다. 다나와에 가격이 없는 부품은 시트 비고에 [다나와 가격 없음]으로 표시됩니다.
- 시트에 없는 부품은 "찾지 못함"으로 표시됩니다. 이때는 "부품 직접 추가"로 넣을 수 있습니다.
- 사양표 양식에 따라 인식이 틀릴 수 있으니, 결과를 한 번 확인해 주세요.
- 호환성 검사와 스펙은 시트에 정리된 값을 기준으로 합니다. 램 다이 정보는 유통사·제조사 공지나 수율을 보고 판단한 값이라 실제 제품과 다를 수 있습니다.
- 일부 사이트는 보안 설정 때문에 OCR이 막힐 수 있습니다. 이때는 캡처해서 다른 사이트(예: 다나와)에서 연 패널에 붙여넣으세요.

### 업데이트 기록
- 스크립트 변경 내역은 패널의 **패치노트 → 스크립트** 탭에서 볼 수 있습니다(1.0부터 기록).
- 부품 추가·삭제 같은 데이터 변경 내역은 위의 **데이터(부품) 패치노트** 링크에서 확인해 주세요.
